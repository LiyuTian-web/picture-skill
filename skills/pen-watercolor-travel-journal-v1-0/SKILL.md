# 钢笔淡彩旅行手账 v1.0

把用户提供的照片重新绘制成一张干净、柔和、可独立成画的钢笔淡彩旅行手账插画。成品必须保留原图画幅比例和场景身份，并让插画、自然留白、文字与四色卡形成同一张连续的水彩纸面。

默认返回生成图片和一段简短中文创作说明。仅在用户要求时附完整提示词或详细构图参数。

## 核心原则

按以下优先级处理冲突：

1. 保留原图比例、核心主体和关键空间关系。
2. 保留原场景的色温、光线、季节与情绪，不把照片改造成无关题材。
3. 使用轻盈钢笔线和低饱和透明淡彩重新绘制，而不是给照片叠加滤镜。
4. 让景物向外自然晕染淡出，与纸面留白连续融合。
5. 在底部形成自然变淡的题字空间，不添加独立色块或版式面板。
6. 右下角只放四枚从原图提取的纯色色卡。
7. 删除一切不属于原场景、题字系统或四色卡系统的装饰。

保留关系优先于保留细节；减少线条优先于增加装饰。

## 输入图像与隐私

- 将用户提供的照片视为编辑目标，而不只是宽泛的风格参考。
- 用户提供照片并要求制作，即表示同意在本次任务中使用图像生成或编辑能力；不要重复询问。
- 不要为补充内容而搜索、浏览或上传照片到用户未指定的位置。
- 不要把原图或生成图写入项目目录，除非用户要求保存，或当前宿主的交付规则要求保存最终成品。
- 在 Codex 中，使用可用的 `imagegen` / `image_gen` 图像编辑能力；先让本地图片在对话中可见，再执行编辑。

## 先读图，再作画

在内部建立一张简短的 **Scene Card**：

- **原始比例：**读取宽高并保持完全相同的横竖方向与比例。
- **核心主体：**选出使照片成立的 1–2 个主体。
- **空间不变量：**记录主体位置、相对大小、朝向、透视、地平线、道路、天际线、轮廓或遮挡关系。
- **焦点与层次：**确定前景、中景、背景以及最清晰的视觉焦点。
- **原生氛围：**判断日景、夜景、暖景、冷景、阴雨、雾气或室内光线。
- **主色候选：**从照片中选出四个覆盖面积或视觉作用最强、彼此可区分的颜色。
- **自然安静区：**寻找可让颜料逐渐变淡并承接文字的底部区域。
- **语言线索：**从可见地点、季节、天气、光线、动作或情绪中提炼题字，不虚构具体地名。

不要把非城市照片强行改成城市，也不要为城市照片添加不存在的建筑、车辆、人物、植物或地标。

## 视觉语言

### 钢笔线稿

- 使用黑色或极深灰黑色的细钢笔线，线条轻、断续、有手绘压力变化。
- 只勾勒主体轮廓、少量结构线和必要的空间线索；不要描完每一个细节。
- 主体可略清晰，背景线条逐渐减少并溶入淡彩。
- 线条不能粗黑、均匀、矢量化，也不能形成漫画描边或机械描图。

### 淡彩水彩

- 使用低饱和、通透、柔和的水彩叠色；保留少量纸白和自然水痕。
- 允许湿画法晕染、轻微颗粒、色边、干笔和不均匀透明度，但整体保持干净。
- 主体颜色来自原图，可比背景稍清晰；背景应减少细节和对比，不能变成高饱和商业插画。
- 纸面带淡淡的冷压水彩纸纤维，不要出现厚重仿古污渍、折痕或立体纸张阴影。

### 无边框自然淡出

- 景物四周使用不规则水彩晕染、羽化、颗粒和干笔逐渐向外淡出。
- 淡出应顺着原场景形状、光线与色块发生，不能形成统一椭圆蒙版或装饰性毛边框。
- 插画与外圈纸面必须平滑过渡并完全融为一体。
- 禁止硬边框、矩形照片框、切割分界线、垂直分割线、隔断、拼贴接缝、胶带、贴纸边、撕纸边、折痕和突然变白的面板。

## 自适应纸面底色

根据原图整体氛围选择一套克制的纸面洗色：

- 夜景或深色场景：使用较深、低饱和的蓝灰、墨绿、炭灰或暖黑调纸面，但保持文字可读。
- 日景、阳光或暖色场景：使用暖米白、淡赭、奶油色或带原图暖色回声的浅纸色。
- 冷色风景、阴天或水景：使用浅灰蓝、雾青、灰绿或冷米白。
- 混合色温：用照片占主导的色温决定底色，再用极轻的次要色洗平衡。

底色必须来自照片氛围，不得套用固定米黄色。留白是颜料自然变薄后的纸面，不是额外添加的白色矩形区域。

## 底部题字系统

在底部自然留白区域放置一个英文标题和一行英文短句。

### 文案规则

- 用户提供文字时，逐字照录，不翻译、不改写、不增加第三行文字。
- 用户没有提供文字时，根据 Scene Card 自动创作：
  - 标题使用 2–5 个英文单词，简短、具体、带旅行手账气息；优先写可见的光线、季节、街道、花园、海岸、雨、风或距离感。
  - 短句使用约 5–10 个英文单词，克制、自然、可独立阅读，不冒充名人名言。
- 不虚构地点、日期、坐标或人物信息。
- 除标题与短句外，禁止任何数字、标签、署名、Logo、水印或伪档案文字。

### 字体与排版

- 使用随性、略不规则、可见笔压变化的英文手写墨迹。
- 拒绝数字字体、标准排版字体、整齐字库感、粗体海报字和书法 Logo 感。
- 标题较大，短句紧随其下且明显更小；两行共享一个自然对齐轴。
- 文字放在底部左侧或中左侧，和右下角色卡取得视觉平衡。
- 保留舒适行距和周围留白；文字不得覆盖核心主体或复杂景物。
- 在生成提示中把最终文字放进引号，要求逐字正确、只出现一次且不出现其他文字。

## 四枚主色色卡

右下角必须放置 **恰好四枚**小型圆角方形色卡：

- 四枚等大、间距一致、排列简洁，不压住主体和题字。
- 每枚色卡只能是一种完全平坦的纯色。
- 四种颜色必须从参考照片本身提取，代表照片最主要或最具结构作用的四个颜色家族。
- 优先覆盖主体色、背景主色、明亮辅助色与最深平衡色；合并过于接近的颜色。
- 禁止使用第五种颜色或与照片无关的流行配色。
- 色卡内部禁止水彩纹理、渐变、阴影、高光、描边、标签、文字、图标和编号。
- 色卡的圆角保持克制，不得变成药丸形、圆形或立体按钮。

## 提示词编译

把最终图像编辑提示组织为六个紧凑部分：

1. **画幅与场景保真：**原始比例、主体、焦点、空间不变量及必须保留的关系。
2. **钢笔淡彩语言：**细钢笔线、透明淡彩、纸张肌理和前后景细节层级。
3. **边缘与留白：**不规则水彩向外淡出、底部自然留白以及连续纸面。
4. **氛围与底色：**原图色温、自动适配的纸面洗色和整体情绪。
5. **文字与色卡：**两行精确英文、手写特征、位置，以及四种从原图提取的色卡颜色。
6. **硬性禁止项：**无边框、无分割、无折痕、无多余装饰、无额外文字、无水印。

只写能转化为可见像素的内容。不要把分析过程、文件路径或设计理论塞进生成提示。

## 生成流程

1. 检查参考照片的真实宽高比、主体和色彩氛围。
2. 建立 Scene Card，确定底部自然留白和右下角色卡的共存方式。
3. 若用户未提供文字，创作一个标题和一行短句；生成前固定为精确文本。
4. 从原图确定四种互相可区分的主色家族。
5. 编译编辑提示，将照片标为唯一编辑目标和唯一颜色来源。
6. 使用图像编辑能力生成一张成品；不要生成拼贴说明页、样机或被拍摄的实体手账。
7. 按质量门检查正常尺寸和缩略图效果。
8. 只有出现明确失败时才针对单一问题再生成一次；不要无限重试。
9. 若用户要求保存文件，使用非破坏性新文件名并报告绝对路径。

## 定向修正

最多进行一次针对性修正：

- **比例错误：**恢复原图横竖方向与精确宽高比，不拉伸主体。
- **场景失真：**恢复缺失的主体、轮廓或空间关系，删除新增物体。
- **线条过重：**减细、打断并减少钢笔线，尤其是背景区域。
- **颜色过艳：**降低非焦点区域饱和度和对比度，保留透明叠色。
- **数字感过强：**增加自然笔压、断线、水彩颗粒和纸纤维，去掉矢量般整齐边缘。
- **边缘像画框：**打散统一轮廓，让颜料按场景形状不规则羽化淡出。
- **留白割裂：**用极浅的场景色和水痕连接画面与底部纸面，删除白色面板感。
- **文字错误：**恢复精确文本、删除多余字符，并加强手写不规则性。
- **色卡错误：**恢复恰好四枚纯色色卡，删除纹理、标签、第五种颜色或非原图色。
- **画面拥挤：**删除装饰元素，扩大自然纸面呼吸区，而不是缩小主体。

## 硬性禁止项

禁止硬边框、照片框、矩形蒙版、椭圆晕影、垂直切割、水平隔断、拼贴接缝、撕纸边、胶带、贴纸、折痕、书脊、笔记本装订孔、桌面样机、手持样机、阴影浮纸、额外装饰、邮票、地图图标、指南针、飞机、咖啡杯、相机、叶片贴纸、日期、坐标、序号、Logo、水印、第三行文字、五枚或更多色卡、渐变色卡、纹理色卡、厚黑描边、漫画风、动漫风、矢量风、油画厚涂、高饱和商业海报、过度锐化、AI 光滑皮肤或统一滤镜。

除非这些物体本来就在照片中且对场景身份必要，否则不要添加。

## 质量门

返回前逐项确认：

- 输出是否保持原图宽高比和横竖方向？
- 核心主体、相对位置、透视与视觉焦点是否仍可辨认？
- 结果是否真正重新绘制为钢笔淡彩，而不是照片滤镜？
- 线条是否细、轻、选择性出现，并在背景逐渐减少？
- 水彩是否低饱和、透明、柔和且保留纸白？
- 四周是否不规则自然淡出，且没有任何硬边框、面板或分割线？
- 底部留白是否由颜料自然变薄形成，并与画面连续融合？
- 纸面底色是否与原图日夜、冷暖和情绪一致？
- 是否只有一个英文标题和一行英文短句，拼写准确且呈手写墨迹？
- 是否恰好四枚圆角方形色卡，并且全部来自原图主色？
- 每枚色卡是否为无渐变、无纹理、无标签的单一纯色？
- 是否没有多余装饰、虚构场景元素、Logo 或水印？
- 缩略图下是否仍能看清主体、题字和四色卡的层级？

若宿主无法保证输出像素比完全一致，应明确说明实际输出尺寸，不要声称已经精确满足比例。


仅在用户明确要求时附完整生成提示词、Scene Card、具体色值或详细构图说明。
